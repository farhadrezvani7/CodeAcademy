# راهنمای نگارش محتوای آموزشی کد آکادمی

مخاطب: دانشجوی ایرانی، از کسی که تازه برنامه‌نویسی را شروع کرده تا برنامه‌نویس باتجربه. هدف: **درست، قابل‌فهم، کوتاه و جذاب**.

## لحن و زبان
- فارسی روان و امروزی، با خطاب «تو» (مثل «یاد می‌گیری»، «امتحانش کن»). نه کتابی و خشک، نه عامیانه‌ی شکسته.
- جمله‌های کوتاه. هر پاراگراف یک ایده. از حشو و جمله‌های کلی («این موضوع بسیار مهم است») پرهیز کن.
- نیم‌فاصله (ZWNJ) درست: «می‌کنی»، «کلاس‌ها»، «ساده‌تر».
- اصطلاحات فنی واقعی ترجمه‌ی ساختگی نمی‌شوند: Widget، State، Future، Stream، async/await، SOLID، Clean Architecture، commit، branch، Pull Request.
- اعداد داخل متن فارسی با ارقام فارسی (۰–۹). کد، نام package و مقادیر فنی داخل backtick با ارقام لاتین.

## بومی‌سازی
- مثال‌ها از زندگی و بازار کار ایران: قیمت به تومان، شماره موبایل ۰۹۱۲…، کد ملی، کد پستی، تقویم شمسی، اپ سفارش غذا، تاکسی اینترنتی، فروشگاه اینترنتی، بانکداری، اپ اتوبوس و مترو، کتاب‌خوانی.
- نام‌های ایرانی در مثال‌ها (علی، سارا، مریم، رضا). از نام تجاری واقعی شرکت‌ها استفاده نکن؛ «اپ سفارش غذا» به‌جای نام برند.
- تشبیه‌ها از تجربه‌های آشنا: صف نانوایی برای Queue، سفارش در رستوران برای Future، کشوهای جاکفشی برای آرایه.
- موضوعات سیاسی، مذهبی و حساس ممنوع.

## کد
- Dart 3 با Null Safety و Flutter فعلی (`super.key`، بدون API منسوخ). هر قطعه کد باید **بدون خطای analyzer** تحلیل شود؛ importهای لازم را بنویس و اگر به نوعی نیاز داری، نسخه‌ی کوچکش را در همان قطعه تعریف کن.
- کامنت‌های داخل کد کوتاه و انگلیسی (جلوگیری از به‌هم‌ریختگی راست‌به‌چپ). رشته‌های فارسی داخل کد مجازند.
- package های مجاز: provider، flutter_bloc، flutter_riverpod، go_router، dio، http، equatable، get_it، shared_preferences، flutter_secure_storage، mocktail، bloc_test، integration_test.
